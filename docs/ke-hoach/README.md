# 📋 docs/ke-hoach — Kế Hoạch & Tài Liệu Dự Án

Thư mục này chứa tất cả kế hoạch, sprint, báo cáo đánh giá và tài liệu bàn giao của dự án.

## Cấu Trúc

| File | Mô Tả |
|---|---|
| `implementation_plan.md` | Kế hoạch triển khai Phase A + Phase B ban đầu |
| `sprint-01.md` | Sprint 01 — Milestone 1-3 (DB, Backend, E2E) |
| `task.md` | Task tracking của phiên hiện tại |
| `walkthrough.md` | Walkthrough Phase B — tổng hợp những gì đã làm |
| `evaluation-report-2026-05-27.md` | Báo cáo đánh giá toàn diện 2026-05-27 |
| `bao_cao_toan_dien.md` | Báo cáo tổng quan toàn diện (tiếng Việt) |
| `comprehensive_project_audit_evaluation.md` | Project audit evaluation (tiếng Anh) |

## Quy Tắc

- Kế hoạch mới → tạo file mới với prefix ngày: `YYYY-MM-DD-ten-ke-hoach.md`
- Không xóa file cũ — chúng là audit trail quan trọng
- Sprint mới → `sprint-02.md`, `sprint-03.md`, ...
- Sau mỗi phiên teamwork → cập nhật `task.md`
